# Огонёк — ежедневный трекер задач

Тёмный ежедневный трекер задач с «огоньком» серии, статистикой, календарём и будильником-напоминаниями.

## Возможности

- **Сегодня** — быстрое добавление задач (Enter), цель дня — 10 задач и больше, отметка выполненных, прогресс-кольцо, переключение дней.
- **Огонёк 🔥** — серия дней подряд, в которые выполнена хотя бы одна задача, плюс рекорд серии.
- **Календарь** — месячная сетка с задачами по дням, выбор дня и добавление задач на любую дату.
- **Статистика** — серия, рекорд, процент выполнения, график за 7 дней, прогресс по категориям, тепловая карта за 15 недель.
- **Напоминания** — будильник со звуком и вибрацией в заданное время задачи (кнопки «Готово» / «Отложить 5 мин»), системные уведомления браузера, экспорт напоминаний в `.ics` с будильником для календаря телефона.
- **Синхронизация** — личный код устройства, который можно ввести на другом устройстве, чтобы видеть те же задачи.

## Технологии

- React 19 + Vite (TypeScript), собственная тёмная тема на CSS
- Netlify Server (Hono) — API `/api/tasks`
- Netlify Database (Postgres) + Drizzle ORM

## Локальный запуск

```bash
npm install
netlify dev --port 8889
```

Netlify CLI поднимает фронтенд, сервер API и локальную базу данных. Миграции лежат в `netlify/database/migrations` и применяются автоматически при деплое. После изменения `db/schema.ts` выполните `npx drizzle-kit generate --name <описание>`.
